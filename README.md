# one_cafe_search

#公開URL
https://one-cafe-search.onrender.com/

# アプリ概要
わんちゃんと一緒に入れる飲食店を紹介する掲示板アプリです。
お店一覧はログインしなくても見れますが、新規投稿時にはログインをお願いする仕様にしてます。
作成者が関東圏在住のため初期投稿は都内のお店が表示されています。
新規投稿は都内に限らず全国のお店を投稿して下さい。
